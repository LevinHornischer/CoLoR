# Motivation 

This course is an introduction to the theory around three interconnected concepts: computability, logic, and randomness. We start with the first concept: Computability theory describes which problems can be solved by an algorithm. This is made precise via so-called Turing machines, the theoretical underpinning of modern computers. Moving to the second concept, we see that not only can computability theory be used to answer questions in logic (e.g., prove Gödel's incompleteness theorem), but logic can be also used to informatively describe computational problems. Finally, time permitting, we look at the third concept: namely, randomness and its interplay with computability. We ask whether access to randomness helps computing power, or if purely random information is not useful information.
